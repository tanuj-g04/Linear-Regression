This project implements linear regression from scratch using Python, without relying on high-level machine learning libraries. It focuses on clearly demonstrating how linear regression works internally, from feature normalization to parameter updates.

The model learns by minimizing Mean Squared Error (MSE) using gradient descent, with weights and bias updated iteratively based on computed gradients. A simple training pipeline ties together normalization, prediction, loss calculation, and evaluation.

Purpose

Designed for educational clarity, this project helps build an intuitive understanding of the mathematics and logic behind linear regression.
